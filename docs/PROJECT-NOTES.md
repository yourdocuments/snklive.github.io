# ওয়েবসাইট প্রোজেক্ট: পার্সোনাল লাইভ ক্লাস / কোর্স রেকর্ডিং টুল

**উদ্দেশ্য:** শুধু নিজের ব্যবহারের জন্য — কোর্স/ক্লাস ভিডিও বানানো সহজ করা। পাবলিক প্রোডাক্ট না।

## ১. ভয়েস ক্লোনিং (মূল ফিচার)
- একবার ভয়েস স্যাম্পল রেকর্ড করা হবে।
- মূল ভিডিওর ভয়েস অটোমেটিক মেন্টরের ভয়েসে কনভার্ট হবে।
- (Backend/API দরকার — Mentor পেজে API URL বসানোর জায়গা আছে)

## ২. ফাইনাল লে-আউট (কনফার্মড)
- **বাম, বড়:** স্লাইড/কনটেন্ট বা আরেকটা ভিডিও; নিচে বাম কোণায় ব্র্যান্ড নেম ব্যাজ; উপরে ডান কোণায় মেন্টরের ভিডিও ফ্রেম
- **ডান পাশ (পুরোটা):** উপরে ছোট "জুম ডেমো" হেডার, নিচে পুরো প্যানেল জুড়ে স্টুডেন্ট লিস্ট (নাম/অ্যাভাটার)

## ৩. কাস্টমাইজেশন
- মেন্টর ফ্রেমের ব্যাকগ্রাউন্ড (রঙ/ইমেজ) বদলানো যাবে
- ব্র্যান্ড নেম টেক্সট এডিটেবল

## ৪. স্কোপ
- পার্সোনাল ইউজ; ভবিষ্যতে client-এর জন্য template হিসেবে ব্যবহার (config.js বদলে)
